# Product Strategy

The winning shape is a game that makes sense in a Reddit feed, is fun in 30 seconds, and becomes more valuable as a community plays it.

## Strong concept tests

A concept is strong when it can answer these questions:

- What is the one-sentence hook?
- Why is it better inside Reddit than on a standalone site?
- What makes a user return tomorrow?
- How does the subreddit/community affect the next player's session?
- What is the smallest playable version judges can understand immediately?

## High-leverage patterns

- Daily puzzle or micro-challenge with a shared result.
- Async competition where each player contributes one run, move, vote, artifact, or modifier.
- Community-authored level modifiers from safe constrained inputs.
- Streaks or collections that do not require spammy posting.
- Lightweight leaderboard with personal best and subreddit-wide goal.
- Rotating theme, enemy, map, prompt, or rule derived from safe daily state.
- "One more try" arcade loop with visible improvement.

## Avoid weak patterns

- A generic web game embedded in Reddit.
- A chat/story generator with little game agency.
- A leaderboard-only game with no deeper hook.
- Clones without a Reddit-native twist.
- Free-form UGC that creates moderation or abuse risk.
- Huge multiplayer scope that cannot be finished.

## Recommended MVP shape

1. A playable 20-60 second loop.
2. One daily modifier or challenge.
3. One persistent progression or collection.
4. One community mechanic.
5. One polished feedback layer: animation, sound toggle, particles, transitions, or satisfying end screen.
6. A README and demo post explaining the loop in under 30 seconds.

## Visual direction

Do not lean on Reddit logos, Snoo, or literal Reddit UI parody. Make a distinct game identity. Use crisp, mobile-readable game UI, strong contrast, readable type, and responsive layouts. If using generated assets, keep them consistent and document licensing/source choices.
