# Submission Checklist

Use this when the game is playable.

## Required

- Devpost project created.
- Reddit app listing created.
- Demo post link in a public subreddit.
- Root `README.md` with build/run/play instructions.
- Project free and available through judging.
- Assets/code ownership is clear.

## Recommended README sections

- Game name and one-sentence hook.
- How to play.
- Why it is Reddit-native.
- Retention mechanic.
- User/community contribution mechanic.
- Tech stack and Devvit template.
- Local development commands.
- Known limitations.

## Devpost content

Draft from `templates/SUBMISSION.md`.

Keep the description practical and judge-friendly:

- What the player does.
- Why the loop is fun.
- How the community changes the game.
- What brings players back.
- How Devvit/Phaser is used.

## Demo video

Optional, under 1 minute. Show:

1. Game start.
2. Core action.
3. Result/score/progress.
4. Daily/community feature.
5. Retry or return hook.
